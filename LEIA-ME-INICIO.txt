RIDERSYNC — PACOTE DE INÍCIO DO DESENVOLVIMENTO

1. Extraia o conteúdo deste ZIP na RAIZ do repositório Git do RiderSync (não dentro de uma subpasta nova).
2. Confirme que a skill está em .claude/skills/ridersync-domain/SKILL.md.
3. Confirme que `claude` funciona no terminal: claude --version
4. Abra o terminal na raiz do repositório e execute UM comando:

   bash INICIAR_IMPLEMENTACAO_RIDERSYNC.sh

O script inicia Claude Code com modelo Opus e permission-mode acceptEdits. O Claude pode editar os arquivos sem pedir confirmação a cada edição, mas ainda pedirá autorização para comandos do terminal conforme suas permissões. Não foi habilitado --dangerously-skip-permissions.

O comando é uma única solicitação de execução ponta a ponta, mas não garante que qualquer projeto complexo seja concluído sem interrupção: limites de contexto, erros, dependências, credenciais e testes podem exigir retomada. O prompt instrui o agente a registrar o progresso em docs/IMPLEMENTATION_PROGRESS.md.

Escopo: React + TypeScript + Vite; NestJS como um único monólito modular; PostgreSQL + Prisma; API REST; testes; Docker Compose.

Editais/oportunidades culturais estão explicitamente adiados. Também ficam fora do MVP pagamentos, IA, avaliações completas e funcionalidades avançadas de agenda.

Antes da execução, mantenha um backup/commit do seu trabalho atual. O script não limpa nem reseta o repositório ou banco.
