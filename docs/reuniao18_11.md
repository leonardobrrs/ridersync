## Geral do Sistema

* Criar um *feed* específico para cada tipo de perfil, pois não é interessante, por exemplo, exibir o campo de "Oportunidades" para um contratante ou casa de show. Avaliar de forma analítica o que é relevante exibir com base no tipo de perfil.

* Formatar a máscara de telefone, ajustando automaticamente para o formato de celular conforme o usuário digita.
* Os menus devem fechar automaticamente ao clicar fora deles. Por exemplo, ao clicar no perfil e abrir o *dropdown*, ele não fecha ao clicar fora, apenas quando se clica novamente no perfil.
* Permitir o envio de mensagens no chat utilizando a tecla "Enter".
